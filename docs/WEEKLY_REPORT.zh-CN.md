## 一句话总结

SkillForge 是一个让 **AI 自己优化自己的提示词** 的系统：上传一份 Agent 技能（SKILL.md），三个专业化大模型助手像铁匠锤打砧台一样反复"评估 → 诊断 → 修改 → 复评"，只保留真正变强的版本，最终交付一份可投入生产使用的改进技能。

---

## 一、项目简介

### 1. 解决什么问题

Agent 技能的打磨传统上靠人肉调提示词：写完一版，跑几个例子，发现不对再改，循环往复。费时、依赖经验、难以量化。

SkillForge 把这个过程工程化、自动化：**你只需定义"什么算好"，AI 自己负责"如何变好"**——灵感来自 Andrej Karpathy 的"自动研究"（Autoresearch）方法论。

### 2. 怎么工作：三 Agent 协作闭环

系统由三个职责单一的 Qwen-Agent 助手组成，共用阿里云百炼（DashScope）模型：

| 智能体 | 角色 | 干什么 |
|--------|------|--------|
| **Executor** | 执行者 / 评分员 | 模拟技能执行、生成测试场景与评估标准、按标准给输出打分 |
| **Analyst** | 失败诊断师 | 分析失败原因，从策略池中选出一种修改策略 |
| **Mutator** | 提示词编辑 | 对 SKILL.md 做**恰好一处**精准修改，产出新版本 |

每一轮循环：**执行 → 评分 → 诊断 → 一处修改 → 完整性守卫 → 复评 → 判断是否保留**。评分达到 100% 即提前收敛，否则最多跑 20 轮。

![三 Agent 协作闭环](skillforge-3agent-loop.png)

> 图：顶部"基线评估与收敛"路径（输入 → 执行 → 评分 → 100%? → 输出改进技能），底部"优化循环（每轮）"路径（Analyst 诊断 → Mutator 修改 → 回归守卫 → Executor 复评 → 严格提升? → 保留/回滚），弧形回环箭头连回"通过 100%?"判断节点。配色采用 Okabe-Ito 色盲安全方案（Nature Methods 期刊标准）。

### 3. 核心机制亮点

- **一次变异只改一处**：任何修改都是单点、可追溯、可对比的
- **严格提升才保留**：新分数必须严格高于基线才留下，否则自动回滚——保证技能只会越改越好，不会退化
- **回归守卫**：结构完整性（frontmatter / 标题 / 体积）硬校验，只拦截不放松
- **并行变异**：每轮最多同时尝试 3 个候选修改，取最优（上限 3，可关）
- **规则锚点评分**：可编程的评估标准（关键词 / 正则 / 格式校验）直接走 Python 判定，不消耗模型调用
- **跨会话经验库（RAG）**：历次成功修复沉淀为经验，后续优化自动检索借鉴（支持标签过滤 / 语义检索 / 混合检索 / 重排），实现"越用越聪明"
- **质量门槛**：只沉淀显著提升的经验（提升幅度 ≥ 15 或最终水位 ≥ 85），过滤小修噪音

### 4. 使用方式（30 秒上手）

```bash
cd skillforge && ./start-dev.sh        # 一键拉起前后端
# 浏览器打开 http://localhost:3000
```

四步操作：**① 上传技能包 zip（或选内置示例）→ ② 审阅 AI 生成的测试场景与评估标准 → ③ 观看三 Agent 优化过程 → ④ 下载改进后的技能 + 完整变更日志**。

技术栈：Python 3.13 + FastAPI + Qwen-Agent + Pydantic；Next.js 15 + React 19 + Tailwind v4 + Recharts。
